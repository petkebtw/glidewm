## Rice scripts (outside this repo)

All in `~/.local/bin`, shared Python in `~/.local/lib/rice/` (`rice.py`, `themes.py`, `hooks.py`, `settings.py`, `widgets.py`, `lyrics.py`, `mpris.py`, `convert.py`, `crashlog.py`), started from `~/.xprofile` (helpers via `rice-supervise`).

- Theme: `theme-switch` (carousel; arrows preview with 120 ms debounce, Enter keeps, Esc reverts, `o` online/offline, `s` source, `g` glass, `r` rice mode). Every theme is a wallpaper; `themes.palette()` extracts colours (OKLab, 72 hue families on a 64x64 4-bit-binned copy, deterministic; disk cache `~/.cache/theme/pal/` keyed by path/mtime/size/light/`PAL_VER`, bump `PAL_VER` when `_palette` changes). `apply()` writes (atomically) `~/.cache/theme/{colors.json,colors.rasi,dwm.Xresources}`, runs `feh`, `xrdb -merge`, and hooks (fastfetch, btop `TTY` theme, cava, Konsole `Rice` colourscheme + `rice` profile with auto opacity, kitty, SDDM on final apply). `themes.look()` sets terminal opacity 0.30-0.85 and picom `blur-strength` 2-6.
- ANSI colours (`hooks.ansi_colors`): OKLCH fixed hues for red/yellow/green/cyan with a 10 deg lean to the accent; Color4/5 are the theme accent/accent2; all at least 5.2:1 contrast.
- Wallpapers: `~/Pictures/wallpapers`, online ones in `online/` (max 150, `MAX_ONLINE`, pruned oldest first, never the active one). Source in `~/.cache/rice/source` (`photo` default since 2026-11-26, `mono`, `wallhaven`, `minimal`, `both`). `photo` = `sync_photo()`: Wallhaven yearly toplist, q `photography` minus digital art/CGI/AI/render, general only, >=1440p 16:9, >=60 favourites, <=12 MB, saved as `photo-<id>` (backups `themes.py.pre-photo`, `rice-settings.pre-photo`). The user called the old sources 2021 slop: the 151 old downloads (GitHub minimal collection, general toplist, mono) were moved to `~/Pictures/wallpapers-old`, not deleted. `mono` = `sync_mono()`: wallhaven queries in three groups (B&W photo, muted photo, ink/line art) with tag exclusions, >=60% neutral wallhaven colours, then `mono_ok()` OKLab chroma gate on the thumbnail and the file; saved as `mono-<id>`. `_palette` gives grey wallpapers an off-white (dark) / charcoal (light) accent (`PAL_VER` 4).
- `rice-themecheck [--fix] [-q]`: verifies the live theme matches the wallpaper (all hooks, picom, blur rules, single picom with `__GL_SYNC_DISPLAY_DEVICE=DP-4`); runs 2 s after every final apply and 10 s after login restore. Log `~/.cache/rice/themecheck.log`.
- Popups: `rice.Card` (class `RiceCard`), `Panel` (settings, class `RicePanel`, slides in from the right edge under the bar). Use `quit_anim` to close a card. `rice.glass_alpha()` = terminal opacity + 0.06. Settings in `~/.cache/rice/settings.json` via `settings.get/put`, `sget/sput` for the `sys` dict.
- Apps: `rice-search` (apps, files via fd, settings, `>` `?` `=` prefixes), `clip-pick` + `clip-daemon` (`~/.cache/clip`), `rice-volume`, `rice-media` (MPRIS card, lyrics from lrclib), `rice-lyrics`, `rice-settings` (sidebar pages; `rice-settings <page>`), `rice-tools`, `rice-convert`, `rice-dl` (cobalt), `rice-pick`, `rice-qr`, `rice-power`, `rice-session`, `rice-lock`, `rice-record`, `rice-scene`, `rice-map`, `rice-shot`, `rice-folder`, `polkit-agent`, `dwm-status`, `dwm-volume`, `audio-fix`, `rice-apply` (applies `sys` settings, also from `~/.xprofile` 3 s after login), `rice-setup-root` (ran 2026-11-16: `/var/lib/rice-sddm`, sudoers for runit-init; now also calls the `rice-sddm` root step).
- `rice-volume`: single instance via `flock` on `~/.cache/rice/volume.lock` + `volume.pid` before importing GTK. A second call sends `SIGUSR1` (`--osd`) or `SIGTERM` (click mode). Keep `SIGUSR1` ignored at the very top of the script. `--at X Y` for bar clicks.
- `rice-media`: grabs the keyboard (Esc/q). Drops a repeated key within 0.4 s; next/prev only act on a playing player; keys logged in `~/.cache/rice/media.log`. Never send `xdotool key space` to a test card: it pauses the REAL player.
- `rice-map` (`Mod+z`): fullscreen zoomable overlay per monitor (primary owns the grab, children via `--mon X Y`); leaving shifts real windows by the camera offset (IPC 8) and focuses the pick (IPC 9). Second `Mod+z` closes it.
- `rice-shot`: captures the X root via GDK; `Print` selects the monitor under the pointer; zoom (scroll, middle pan, `0`), auto-pan while selecting, OCR ("Copy text", key `x`) with tesseract and PPM input (its leptonica cannot read PNG); languages in `~/.local/share/rice/tessdata` with `TESSDATA_PREFIX`.
- `rice-record`: ffmpeg x11grab, countdown, audio and per-app capture routing (null sink `rice_rec`; `route_restore()` and `leftovers()` clean up).
- `rice-lock`: own X11 locker (`unix_chkpwd`); use `grab_focus_without_selecting()` in the entry. `rice-power` uses one armed button with a 4 s window.
- `rice-supervise CMD` restarts a dying helper (gives up after 5 quick crashes, exits quietly on SIGTERM or when X is gone).
- Crashes of rice scripts go to `~/.cache/rice/crash.log`; check it first when a script vanishes.
- kitty (test only, Konsole stays default): `~/.config/kitty/kitty.conf` includes `~/.cache/theme/kitty.conf` written by `hooks.kitty()` (USR1 recolours live). Tuned to match Konsole's JetBrains Mono 10 on this 91 dpi screen: `font_size 8.75`, `modify_font cell_height -2px`, `text_composition_strategy platform`, `bold_font JetBrains Mono ExtraBold`, `window_padding_width 4.25 11 11 11`.
